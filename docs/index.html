RevoLinux

Clean uninstaller for Fedora - DNF and Flatpak, with leftover purge. v0.1.0
Download for Linux x86_64 (tarball) Source on GitHub

Quick install

curl -LO https://github.com/lsupwp/Revo-Uninstall-Clone-Linux-/releases/download/v0.1.0/revolinux-0.1.0-x86_64-unknown-linux-gnu.tar.gz
tar -xzf revolinux-0.1.0-x86_64-unknown-linux-gnu.tar.gz
cd revolinux
./install.sh

Installs to /usr/local and adds RevoLinux to your application menu. Per-user install without root: PREFIX="/home/lsupwp/.local" ./install.sh.

Run without installing

tar -xzf revolinux-0.1.0-x86_64-unknown-linux-gnu.tar.gz
./revolinux/revolinux

Requires Fedora with dnf5. Flatpak is optional. pkexec is used for admin authentication when system packages change.

Verify the download

curl -LO https://github.com/lsupwp/Revo-Uninstall-Clone-Linux-/releases/download/v0.1.0/revolinux-0.1.0-x86_64-unknown-linux-gnu.tar.gz.sha256
sha256sum -c revolinux-0.1.0-x86_64-unknown-linux-gnu.tar.gz.sha256

What it does

Uninstall

Removes the app with dnf5 or flatpak.

Purge scan

Finds config, cache, data, temp and desktop files left behind.

Your choice

Each leftover path has a checkbox and a confirmation dialog.

Safe

RPM-owned files are never offered. System paths use polkit.

CLI

revolinux list
revolinux scan <id>
revolinux purge <id>          # read-only preview
revolinux purge <id> --yes    # uninstall + delete HIGH/MED leftovers
